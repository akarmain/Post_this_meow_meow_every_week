# Post this meow-meow every week

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Небольшая утилита для macOS: превращает PNG котика с прозрачным фоном в квадратный ролик 720×720 со звуком — готовый к заливке в Reels, Shorts и TikTok. Кот уменьшается, уезжает вправо вниз и слегка «парит», левая часть кадра остаётся свободной под облачко или подпись.

## Демо

![Демо-ролик](demo.gif)

Со звуком: [YouTube](https://youtu.be/_VqhW7h5ajo) · [mp4](https://s3.akarmain.ru/S/KkgIl.mp4)

## Что понадобится

- Mac с `zsh` (он есть в macOS по умолчанию);
- [FFmpeg](https://ffmpeg.org/). Если Homebrew уже установлен: `brew install ffmpeg`;
- PNG котика с прозрачным фоном.

## Как запустить

1. Скачайте репозиторий или откройте его папку в Терминале.
2. Выполните команду, указав путь к PNG:

```zsh
zsh make_cat_video.sh '/путь/к/котику.png'
```

Скрипт создаст на рабочем столе 30-секундный ролик MP4 со звуком из `cat-default-audio.m4a` — трек лежит в репозитории и подставляется автоматически. Имя содержит дату и время, поэтому старые ролики не перезаписываются.

Чтобы подставить свой звук из другого видео или аудиофайла, передайте его вторым аргументом (короткий трек зациклится до 30 секунд):

```zsh
zsh make_cat_video.sh '/путь/к/котику.png' '/путь/к/звуку.mp4'
```

## Параметры готового ролика

- 720×720, квадрат;
- 30 кадров в секунду;
- 30 секунд;
- H.264 + AAC — подходит для загрузки в соцсети;
- котик размером 450 px расположен справа внизу (`x=270`, `y=220`) и чуть «парит».

Фон-шаблон и звуковая дорожка уже лежат в репозитории. Скрипт не содержит личных путей: он сохраняет результат на рабочий стол **того пользователя, который его запустил**.

## Если нужно изменить композицию

В `make_cat_video.sh` измените значения `scale=450:450`, `x=270` и `y=220` в строке `overlay`.
